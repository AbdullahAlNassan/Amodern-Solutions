# Amodern Solutions Website

## Overview
A modern business website for "Amodern Solutions", a web development company that builds websites for businesses like restaurants, barbershops, cafes, salons, and more.

## Tech Stack
- **Backend**: Python Flask
- **Frontend**: HTML, CSS, JavaScript (vanilla)
- **Font**: Inter (Google Fonts)

## Project Structure
```
app.py                   - Flask application (main entry point, port 5000)
templates/
  index.html             - Main single-page website
static/
  css/style.css           - All styling (dark theme, responsive)
  js/main.js              - Navigation, animations, contact form
```

## Features
- Responsive single-page website with smooth scrolling
- Animated stats counters
- Service cards for different business types
- Portfolio showcase with gradient cards
- Step-by-step process section
- Pricing tiers (Starter, Professional, Enterprise)
- Client testimonials
- Contact form with AJAX submission
- Mobile navigation menu
- Scroll-based fade-in animations

## Running
```
python app.py
```
Server runs on port 5000.
